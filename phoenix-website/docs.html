PHOENIX CLI Documentation

v0.4.2

Everything you need to install, configure, and use the PHOENIX CLI. This reference covers provider setup, all available command flags, and system health checks.

Installation

STABLE

PHOENIX supports multiple installation methods across Termux, Linux, and macOS. Choose the method that fits your environment.

phone_android Termux (Recommended)

Terminal — bash 
# Update package repos and install
pkg update && pkg install phoenix-cli

language PyPI (pip)

Terminal — bash 
# Install via pip (requires Python 3.10+)
pip install phoenix-cli

build Build from Source

Terminal — bash 
# Clone and install from source
git clone https://github.com/sufiyan-sabeel/Phoenix.git
cd Phoenix
pip install -e .
phoenix init

settings Initialize Configuration

Terminal — bash 
# Quickstart config with default provider
phoenix init --quickstart
check_circle
Verified on: Termux Android 12/13/14, Ubuntu 22.04+, Debian 12, macOS 14+

API Provider Configuration

REQUIRED

PHOENIX supports multiple AI providers. Configure your preferred provider using environment variables or the built-in setup wizard.

OpenRouter (Recommended)

Terminal — bash 
# Set your OpenRouter API key
export OPENROUTER_API_KEY="sk-or-v1-xxxxxxxxxxxx"

# Configure PHOENIX to use OpenRouter
phoenix config set provider openrouter
phoenix config set model deepseek/deepseek-chat

Groq (Ultra-low Latency)

Terminal — bash 
# Set your Groq API key
export GROQ_API_KEY="gsk_xxxxxxxxxxxx"

# Configure PHOENIX to use Groq
phoenix config set provider groq
phoenix config set model llama-3.3-70b-versatile

Ollama (Local Offline)

Terminal — bash 
# Configure PHOENIX for local Ollama
phoenix config set provider ollama
phoenix config set ollama-url http://localhost:11434
phoenix config set model codellama:13b

CLI Command Flags

REFERENCE

Complete reference for all PHOENIX CLI flags and subcommands. Flags can be combined and order does not matter.

Global Flags

Flag Short Description
--help -h Show help message and exit
--version -v Print version information and exit
--verbose -V Enable verbose debug output
--config -c Path to config file (default: ~/.phoenix/config.json)
--provider -p Override AI provider for this session
--model -m Override model for this session
--no-color Disable colored terminal output
--json -j Output results in JSON format

Subcommands

Command Description Example
init Initialize PHOENIX configuration phoenix init --quickstart
config View or modify configuration settings phoenix config set provider openrouter
health Run system health verification checks phoenix health --verbose
code AI-assisted coding and diff inspection phoenix code --diff ./src
shell Natural language shell command generation phoenix shell "compress all pngs"
adb Android ADB bridge commands phoenix adb --tap-record flow
update Update PHOENIX to latest version phoenix update --check

Usage Examples

Terminal — examples 
# Check version
phoenix --version

# AI-assisted code diff
phoenix code --diff ./src/services

# Pipe output to AI for summarization
git status | phoenix "summarize changes"

# Override provider per-session
phoenix shell --provider groq "list large files"

# Health check with JSON output
phoenix health --verbose --json
