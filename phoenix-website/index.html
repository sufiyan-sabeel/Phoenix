Quickstart Guide

Full Manualopen_in_new

1. Export your API token in your environment or let PHOENIX manage your secrets securely via keychain:

export OPENROUTER_API_KEY="sk-or-v1-..."

2. Execute an interactive prompt or pipe command outputs directly into the reasoning engine:

git status | phoenix "summarize changes and suggest commit title"

3. Generate executable shell scripts safely:

phoenix make-script "backup docker volumes daily at 2am"
